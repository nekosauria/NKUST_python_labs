# 📚 數學符號白話文大百科：從高中基礎到資工/AI 應用

本對照表專為工程師與資訊科學研究者設計。涵蓋高中數學核心、微積分、演算法複雜度、離散數學與線性代數，並提供白話文與程式碼對比。

## 1. 高中基礎數學核心（奠基代數與函數）

這部分是所有高等數學的基石，程式開發中也經常出現。

| 符號 | 名稱 / 怎麼讀 | 白話文意思 | 程式碼對比 / 範例 |
| :---: | :--- | :--- | :--- |
| $\lvert x \rvert$ | Absolute value / 絕對值 | 去掉正負號，只留下數值的大小（數字到原點的距離）。 | `abs(x)` |
| $f(x)$ | Function / 函數 | 給它一個輸入值 $x$，它會透過內部邏輯吐出一個輸出值。 | 就是程式裡的 `def func(x): return output` |
| $f \circ g(x)$ | Composite function / 複合函數 | 連續執行。先把 $x$ 丟進 $g$ 函數，算出的結果再丟進 $f$ 函數。 | `f(g(x))` |
| $\pm$ | Plus-minus / 正負 | 代表有兩種可能，一個是加、一個是減。 | 一次解出兩個答案，例如一元二次方程的公式解。 |
| $a^n$ | Exponent / 次方 (冪) | 把 $a$ 連續乘以自己 $n$ 次。 | `a ** n` 或 `math.pow(a, n)` |
| $\sqrt{x}$ | Square root / 平方根 | 找出一個正數，它自己乘以自己會等於 $x$。 | `math.sqrt(x)` |
| $\log_a b$ | Logarithm / 對數 | 詢問「$a$ 的幾次方會等於 $b$？」。 | `math.log(b, a)`（若沒寫底數，資工預設為 2，數學預設為 $e$ 或 10） |
| $\sin \theta$ / $\cos \theta$ | Sine / Cosine (三角函數) | 直角三角形中，邊長與角度的比例關係。 | `math.sin(rad)` / `math.cos(rad)`（2D/3D 遊戲與影像旋轉的核心） |

## 2. 高中數列、排列組合與統計（演算法與機率核心）

| 符號 | 名稱 / 怎麼讀 | 白話文意思 | 程式碼對比 / 應用 |
| :---: | :--- | :--- | :--- |
| $a_n$ | Sequence term / 數列項 | 陣列或清單中，第 $n$ 個位置的資料。 | `array[n]`（注意：數學索引通常從 1 開始，寫 Code 從 0 開始） |
| $d$ / $r$ | Common diff / ratio | 等差數列的「公差」/ 等比數列的「公比」。 | 迴圈中的步進值（如 `range(start, end, d)`） |
| $n!$ | Factorial / 階乘 | 從 $n$ 開始，一整路往下乘到 1。 | 暴力破解法、排列組合的總可能數。 |
| $P^n_k$ 或 $P(n, k)$ | Permutation / 排列 | 從 $n$ 個東西裡面，**拿出 $k$ 個來排順序**（順序不同算不同東西）。 | `import itertools; itertools.permutations(data, k)` |
| $C^n_k$ 或 $\binom{n}{k}$ | Combination / 組合 | 從 $n$ 個東西裡面，**單純挑選出 $k$ 個**（不限制、不理會順序）。 | `import itertools; itertools.combinations(data, k)` |
| $A \setminus B$ | Difference / 差集 | 在集合 A 裡面，但**不在**集合 B 裡面的東西。 | `set_A - set_B` |
| $E(X)$ | Expected value / 期望值 | 事件長期實驗下來，平均每次預期會獲得的數值。 | 強化學習（Reinforcement Learning）中計算獎勵的核心。 |

## 3. 微積分與最佳化（微積分大會師、AI 梯度下降核心）

在資工與 AI 實務中，微積分主要用來尋找「最佳參數」（例如讓錯誤率 Loss 降到最低）。

| 符號 | 名稱 / 怎麼讀 | 在資工/AI 代表的白話文意思 | 程式碼對比 / 應用場景 |
| :---: | :--- | :--- | :--- |
| $\lim_{x \to a}$ | Limit / 極限 | 當 $x$ 無限趨近於 $a$ 時，函數輸出值會貼近哪一個數字。 | 微積分的起點，用來定義圖形切線斜率。 |
| $f'(x)$ 或 $\frac{df}{dx}$ | Derivative / 微分 (導函數) | 計算函數在某個點的**瞬間變化率（斜率）**。 | 用來判斷參數往哪個方向調整，可以讓數值改變。 |
| $\frac{\partial f}{\partial x}$ | Partial derivative / 偏微分 | 當函數有多個變數時，**只對其中一個變數**求斜率，其他變數當作常數。 | 神經網絡權重更新時，單獨計算某一個神經元權重的影響。 |
| $\nabla f$ | Gradient / 梯度 | 把函數對所有變數的偏微分包成一個向量，指向**函數增長最快**的方向。 | **梯度下降法 (Gradient Descent)**：`w = w - lr * gradient`。 |
| $\sum$ | Sigma / 加總 | 離散型態的累加。把指定範圍內的東西**通通加起來**。 | 類似 `sum([x for x in data])` |
| $\int f(x) dx$ | Integral / 積分 | 連續型態的累加。計算函數曲線下方的**累積總和（面積）**。 | 在機率密度函數（PDF）中用來計算連續隨機變數的機率。 |
| $\arg\max_x f(x)$ | Arguments of the max | 讓後面那個函數產出最大值時的**輸入變數 $x$ 是誰**（回傳 Index，而非最大值本身）。 | 分類模型預測時，找出機率最高的那一個類別標籤（如：`preds.argmax(dim=-1)`）。 |

## 4. 演算法與時間複雜度（資料結構與演算法必備）

| 符號 | 名稱 / 怎麼讀 | 白話文意思 | 舉例 / 程式碼情境 |
| :---: | :--- | :--- | :--- |
| $O(n)$ | Big O / 大 O 符號 | 演算法在**最壞情況下**的時間（或空間）複雜度上限。 | 二元搜尋（Binary Search）是 $O(\log n)$；雙層迴圈是 $O(n^2)$。 |
| $\Omega(n)$ | Big Omega / 大 Omega | 演算法在**最好情況下**的時間複雜度下限。 | 已經排好序的陣列，用泡沫排序法（Bubble Sort）只要 $\Omega(n)$。 |
| $\Theta(n)$ | Big Theta / 大 Theta | 演算法的**精確綁定**（同時滿足上限與下限），代表速度卡在中間。 | 合併排序法（Merge Sort）不論好壞，永遠都是 $\Theta(n \log n)$。 |

## 5. 離散數學與邏輯（資工邏輯大腦、密碼學與編譯器核心）

| 符號 | 名稱 / 怎麼讀 | 白話文意思 | 程式碼對比 |
| :---: | :--- | :--- | :--- |
| $\neg$ 或 $\sim$ | Not / 非 | 邏輯「反轉」，對與錯互換。 | `!` (如 `if not is_admin:`) |
| $\land$ | And / 且 | 兩個條件都必須是 True，結果才是 True。 | `&&` 或 `and` |
| $\lor$ | Or / 或 | 兩個條件只要有一個是 True，結果就是 True。 | `\|\|` 或 `or` |
| $\oplus$ | XOR / 互斥或 | 兩個條件**一個是一、一個是零**（不相同）時，結果才是 True。 | `^` (在加密、雜湊演算法極常用) |
| $\forall$ | For all / 任意 | 對於集合中的**每一個**元素都成立。 | 類似 `Array.every()` 或迴圈檢查所有項目 |
| $\exists$ | Exists / 存在 | 集合中**至少有一個**元素成立。 | 類似 `Array.some()` |
| $\lfloor x \rfloor$ | Floor / 高斯符號 (下取整) | 去掉小數點，**無條件捨去**。 | `math.floor(x)` 或 `int(x)` |
| $\lceil x \rceil$ | Ceiling / 天花板符號 (上取整) | 只要有小數點，**無條件進位**。 | `math.ceil(x)` |
| $a \equiv b \pmod m$ | Congruence / 模餘同餘 | $a$ 除以 $m$ 的餘數，跟 $b$ 除以 $m$ 的**餘數一模一樣**。 | `a % m == b % m`（RSA 加密演算法的核心） |

## 6. 線性代數與高維空間（3D 遊戲、AI Token Embedding 核心）

| 符號 | 名稱 / 怎麼讀 | 白話文意思 | 程式碼對比 (NumPy) |
| :---: | :--- | :--- | :--- |
| $\mathbf{v}$ 或 $\vec{v}$ | Vector / 向量 | 在程式裡就是**一維陣列（List/Array）**，代表高維空間中的一個特徵點。 | Embedding 向量，例如 `[0.12, -0.44, 0.91]`。 |
| $\mathbf{A}$ | Matrix / 矩陣 | 在程式裡就是**二維陣列（2D Array）**。 | 在影像處理中，一張灰階圖片就是一個二維矩陣。 |
| $\mathbf{A} \cdot \mathbf{B}$ | Dot Product / 內積 | 兩個陣列對應位置相乘後加總，產出一個數字。 | 常用於計算**特徵相似度**、Transformer 的注意力機制。 |
| $\mathbf{A} \times \mathbf{B}$ | Matrix Multiplication | 兩個二維陣列（矩陣）相乘，產出一個新矩陣。 | 深度學習中，資料通過線性層（Linear Layer）的本質：`Y = X @ W + B`。 |
| $\|\mathbf{v}\|_2$ | L2 Norm / L2 範數 | 計算這個向量在空間中到原點的**直線距離（歐幾里得距離）**。 | 機器學習中的 L2 正規化（Weight Decay），防止模型過擬合。 |

## 💡 終極破譯公式心法：用寫 Code 的思維學數學

1. **所有的「大型符號」都是迴圈**：
   看到 $\sum$ 或是 $\prod$，不要覺得那是高等數學。在工程師眼裡，它就只是一個 `for loop`。把底部的指標（如 $i=1$）當作迴圈初始值，把頂部的數字（如 $n$）當作終止條件，中間的公式就是迴圈主體。
2. **微積分交給電腦，你負責看懂方向**：
   寫程式時不需要手動算偏微分（$\partial$）。像 PyTorch 的 `loss.backward()` 會自動幫你完成。你唯一需要記住的是：**微分代表斜率，斜率代表方向；順著斜率往下走，就能找到最精準的 AI 模型參數**。
