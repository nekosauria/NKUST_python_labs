# MSE vs MAE 比較說明

## 數學定義

**MSE（均方誤差）**

$$MSE = \frac{1}{n}\sum(y_i - \hat{y}_i)^2$$

**MAE（平均絕對誤差）**

$$MAE = \frac{1}{n}\sum|y_i - \hat{y}_i|$$

---

## 優缺點對照表

| 面向 | MSE | MAE |
|------|-----|-----|
| 對異常值敏感度 | ❌ 高（誤差平方放大影響） | ✅ 低（線性懲罰） |
| 梯度穩定性 | ✅ 平滑，處處可微 | ⚠️ 在 0 點不可微 |
| 收斂速度 | ✅ 誤差大時梯度大，收斂快 | ❌ 梯度恆定，接近最優時收斂慢 |
| 解釋性 | ❌ 單位是原始單位的平方 | ✅ 單位與原始數據相同，直觀 |
| 最優解唯一性 | ✅ 嚴格凸函數，唯一最小值 | ⚠️ 可能有多個最小值 |

---

## 核心差異直覺

```
假設真實值 y = 10，有兩種預測情境：

情境 A：誤差 = 1, 1, 1, 1, 6   （有一個大誤差）
情境 B：誤差 = 2, 2, 2, 2, 2   （誤差均勻分布）

MSE_A = (1+1+1+1+36)/5 = 8.0   ← 對大誤差懲罰重
MSE_B = (4+4+4+4+4)/5  = 4.0

MAE_A = (1+1+1+1+6)/5  = 2.0   ← 大誤差影響較小
MAE_B = (2+2+2+2+2)/5  = 2.0   ← 兩者相同！
```

---

## 以 y = ax + b 為例

### 無異常值時

兩條回歸線幾乎重疊，MSE 與 MAE 效果相同。

### 有異常值時

- **MSE**：異常點的誤差被平方放大，對斜率 `a` 的影響遠大於其他正常點，回歸線被大幅拉偏。
- **MAE**：對所有點一視同仁，不因單一大誤差失去立場，回歸線仍貼近多數資料點。

### 直覺總結

| | 最小化目標 | 等價於擬合 |
|---|---|---|
| MSE | 誤差的平方和 | **均值**附近 |
| MAE | 誤差的絕對值和 | **中位數**附近 |

---

## 什麼時候選哪個？

**選 MSE 當：**
- 大誤差代價很高，需要重點懲罰
- 數據乾淨，異常值少
- 希望梯度平滑、訓練穩定
- 回歸任務的預設首選

**選 MAE 當：**
- 數據含有較多異常值（outliers）
- 希望模型對多數數據表現好，而非被少數極端值帶偏
- 需要直觀的誤差解釋（單位與原始數據一致）

---

## 進階選擇：Huber Loss（兩者折衷）

小誤差用 MSE（平滑），大誤差用 MAE（抗異常值）。

```python
loss = torch.nn.HuberLoss(delta=1.0)
```

$$Huber = \begin{cases} \frac{1}{2}(y-\hat{y})^2 & |error| \leq \delta \\ \delta \cdot |error| - \frac{1}{2}\delta^2 & |error| > \delta \end{cases}$$

---

## PyTorch 範例

```python
import torch

y_pred = model(x)
y_error = y - y_pred

# MSE
m_loss = (y_error ** 2).mean()

# MAE
m_loss = torch.abs(y_error).mean()

# Huber（折衷）
loss_fn = torch.nn.HuberLoss(delta=1.0)
m_loss = loss_fn(y_pred, y)
```
